Cookies and Advertising Identifiers

The Application uses the Google Advertising ID (AAID), a user-resettable identifier assigned by the Android operating system, through AdMob to serve and measure advertisements (including personalised advertising in regions where the user has provided consent under GDPR / IAB TCF v2). Users can reset their Advertising ID or opt out of personalised advertising at any time via Android Settings > Google > Ads.

In addition, the Application uses a Firebase Installation ID (FID) — an anonymous, app-instance-scoped identifier generated by the Firebase SDK — for purposes such as crash report grouping and aggregate analytics. The FID is reset whenever the Application is uninstalled and reinstalled or when application data is cleared.

The Application itself does not use traditional browser cookies. However, third-party services integrated within the Application (such as AdMob and Firebase) may use cookies, web beacons, SDK identifiers and similar technologies to deliver advertisements, measure performance, detect abuse and prevent fraud. Please refer to each third party's Privacy Policy linked below for further detail on the technologies they use.
